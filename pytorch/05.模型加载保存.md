# 05.模型加载保存

## 1. 加载模型（torch.load() + model.load_state_dict()）
```python
    # ==== 定义 model
    config = CONFIGS[args.model_type]

    num_classes = 10 if args.dataset == "cifar10" else 1000

    model = VisionTransformer(config, args.img_size, zero_head=True, num_classes=num_classes)

    # ==== load pretrained_model
    state_dict = torch.load(args.pretrained_dir)
    print(' #### state_dict: ', state_dict.keys)
    print(' #### type(state_dict): ', type(state_dict))

    # ==== 打印向量名 和 权重
    state_dict_del = {}
    for name, weights in state_dict.items():
        if not ('head.weight' in name or 'head.bias' in name):
            state_dict_del[name] = weights
    print(' #### state_dict_del: ', state_dict_del.keys)

    # ==== model 初始化
    model.load_state_dict(state_dict_del, False)
```



PyTorch 模型的加载流程通常包括以下几个步骤：
1. **文件到 state_dict**：首先，我们需要从文件中加载模型的状态字典（state_dict）。这通常通过 `torch.load` 函数来实现，这个函数可以从一个包含了模型状态字典的 PyTorch 检查点文件中加载数据。例如：

```python
state_dict = torch.load('model.pth')
```

在这个例子中，'model.pth' 是一个 PyTorch 检查点文件，它包含了模型的状态字典。

2. **state_dict 到 model**：一旦我们有了状态字典，我们就可以将其加载到模型中。这通常通过模型的 `load_state_dict` 方法来实现。例如：

```python
model = Model()  # 用你的模型结构初始化一个模型实例
model.load_state_dict(state_dict)
```

在这个例子中，`Model` 是你的模型类，你需要先初始化一个模型实例，然后使用 `load_state_dict` 方法将状态字典加载到这个模型实例中。

3. **model 到 GPU**：如果你有 GPU 并且想要在 GPU 上运行你的模型，你可以使用模型的 `to` 方法将模型移动到 GPU。例如：

```python
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = model.to(device)
```

在这个例子中，我们首先检查是否有可用的 GPU，如果有，我们就使用 'cuda' 作为设备字符串，否则我们使用 'cpu'。然后我们使用模型的 `to` 方法将模型移动到指定的设备。

这就是一个典型的 PyTorch 模型加载流程，从文件到状态字典，再到模型，最后到 GPU。
